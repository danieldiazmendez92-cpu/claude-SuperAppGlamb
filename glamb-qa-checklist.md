# GLAMB OS — Checklist QA funcional

## Objetivo

Checklist obligatoria antes de aprobar cambios e integrar a `glamb-os-stable.html`.

---

# 1. Navegación general

- [ ] Puedo ir a Centro.
- [ ] Puedo ir a Clientes.
- [ ] Puedo ir a Agenda.
- [ ] Puedo ir a Caja.
- [ ] Puedo ir a Equipo.
- [ ] En pantalla chica aparece navegación alternativa.
- [ ] No hay módulos duplicados que confundan.

---

# 2. Clientes

- [ ] Puedo crear cliente.
- [ ] El cliente nuevo aparece en la lista.
- [ ] WhatsApp se puede cargar.
- [ ] Puedo abrir perfil de cliente.
- [ ] Puedo marcar VIP.
- [ ] Puedo crear turno desde cliente.

---

# 3. Equipo

- [ ] Puedo crear colaboradora.
- [ ] Puedo seleccionar servicios agrupados.
- [ ] Puedo configurar disponibilidad por día.
- [ ] Puedo indicar si recibe turnos.
- [ ] La colaboradora aparece en Agenda si recibe turnos.

---

# 4. Agenda desktop/tablet

- [ ] Se ve grilla por profesionales.
- [ ] Se ven horarios a la izquierda.
- [ ] Se ven turnos como bloques.
- [ ] Puedo crear turno.
- [ ] Puedo cambiar intervalo 15/30/60.
- [ ] Puedo filtrar por profesional.
- [ ] Puedo filtrar por grupo.
- [ ] Puedo abrir detalle de turno.
- [ ] Puedo cambiar estado.
- [ ] Puedo marcar pago/seña.
- [ ] Se calculan huecos.
- [ ] Puedo crear turno desde hueco.
- [ ] No permite solapamientos.

---

# 5. Agenda móvil

- [ ] Se ve agenda panorámica para recepción/admin/dueño.
- [ ] Se ven horarios a la izquierda.
- [ ] Se ven profesionales por columna.
- [ ] Se ven turnos como bloques.
- [ ] Se ven bloqueos.
- [ ] Se puede crear nueva cita.
- [ ] Se puede crear cita desde hueco.
- [ ] La vista colaboradora puede ser lista simple.
- [ ] No se ve como copia literal de Fresha.
- [ ] Mantiene identidad GLAMB.

---

# 6. Ventas & Caja

- [ ] Puedo abrir caja con monto inicial.
- [ ] Puedo registrar retiro.
- [ ] Puedo cerrar caja con efectivo contado.
- [ ] Puedo elegir origen: turno en agenda.
- [ ] Puedo elegir origen: cliente existente sin turno.
- [ ] Puedo elegir origen: cliente nuevo.
- [ ] Cliente nuevo abre creación de cliente.
- [ ] Puedo registrar venta con un servicio.
- [ ] Puedo registrar venta con más de un servicio.
- [ ] Cada línea tiene colaboradora.
- [ ] Cada línea tiene servicio.
- [ ] Cada línea tiene precio editable.
- [ ] Se ve seña por línea.
- [ ] Seña no descuenta del total visible.
- [ ] Puedo cargar propina.
- [ ] Puedo cargar adicional.
- [ ] Puedo pagar con un medio.
- [ ] Puedo usar pago mixto.
- [ ] Total de pagos coincide con total a cobrar.
- [ ] Puedo guardar para cobrar después.
- [ ] Pendiente aparece en la lista.
- [ ] Puedo cobrar pendiente.
- [ ] Se crea ticket.
- [ ] Ticket aparece en Tickets del día.
- [ ] Caja del día muestra movimientos.

---

# 7. Centro de Mando

- [ ] KPIs se renderizan.
- [ ] Se ve caja esperada.
- [ ] Se ven turnos del día.
- [ ] Se ven alertas.
- [ ] Se ven oportunidades.
- [ ] No queda información rota o vacía.

---

# 8. Visual básico

- [ ] No se rompió layout principal.
- [ ] No desapareció menú.
- [ ] No hay scroll imposible de usar.
- [ ] No se mezclaron estilos contradictorios.
- [ ] Mobile y desktop siguen diferenciados.
