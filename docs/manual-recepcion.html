1.Acceso y roles

GLAMB OS se abre en el navegador desde glamb-os.web.app. Ingresá con tu correo y contraseña.

El sistema tiene tres niveles de acceso:

RolAcceso
Administración Acceso completo: clientes con datos de contacto, agenda, caja completa, catálogo, equipo, RRHH, finanzas, comunicaciones, Athenas.
Recepción Clientes (sin datos de contacto), agenda, caja completa. Sin acceso a finanzas ni RRHH.
Colaboradora Solo agenda (día actual) y sus propias ventas en caja. Sin acceso a datos de clientes, finanzas ni equipo.
Este manual aplica al rol Recepción y Administración Algunas funciones (RRHH, Finanzas, Catálogo, Equipo, Comunicaciones) pueden no estar disponibles si tu usuario es de nivel recepción sin permisos completos.

Gestión de usuarios

Para crear o editar usuarios del sistema andá a Equipo → Usuarios. Desde ahí podés asignar roles y vincular colaboradoras con sus cuentas de acceso.

No compartir credenciales Cada persona debe tener su propio usuario. Los registros de cobros, cambios de estado y acciones quedan asociados al usuario que los realizó.

2.Panel de inicio

El Panel (♦) es la pantalla de bienvenida. Muestra un resumen en tiempo real del día.

2.1 Indicadores del día

IndicadorQué muestra
Turnos de hoyTotal de turnos activos del día.
Confirmados / En curso / CompletadosEstado de los turnos del día.
Ventas del díaTotal cobrado en tickets confirmados.
Pendientes de cobroServicios guardados que todavía no se cobraron.
Saldo en cajaEfectivo esperado según apertura + cobros − retiros − gastos.

También muestra los próximos turnos y accesos rápidos a las funciones más usadas.

3.Clientes ♡

El módulo de clientes (ícono ♡) es la base de datos del salón: perfil, historial de visitas, etiquetas, notas y estadísticas.

3.1 Buscar y ver perfil

  1. Ingresá el nombre, apellido o teléfono en la barra de búsqueda.
  2. Tocá Ver perfil en la tarjeta del cliente.
  3. El perfil muestra: datos de contacto, visitas, ticket promedio, etiquetas, notas, historial completo y reseñas.

3.2 Crear cliente

  1. Tocá + Nuevo cliente.
  2. Completá nombre, apellido, teléfono y email (los últimos dos son opcionales pero recomendados para recordatorios).
  3. Tocá Guardar.
También podés crear clientes desde la Agenda Al crear un turno, si el cliente no existe, hay un botón para crearlo sin salir de la agenda.

3.3 Editar datos

Desde el perfil del cliente, tocá Editar datos. Podés modificar nombre, apellido, teléfono, email y nota clave.

Solo admins pueden editar La edición y eliminación de clientes es exclusiva del rol administración.

3.4 Historial de visitas

El historial muestra lo que se realizó realmente, no solo lo que estaba agendado:

CasoLo que muestra
Turno cobrado sin cambiosServicio, adicionales, colaboradora, precio real, fecha.
Se cambió el servicio al cobrarEl servicio realizado + nota "Agendado: [servicio original]".
Se agregaron servicios extraServicio principal + lista de adicionales y extras.
Venta sin turno (walk-in)Aparece con label "Sin turno".
Turno cancelado o no cobradoMuestra datos del turno original.

Usá el filtro arriba del historial para ver solo ciertos estados (activos, cancelados, todos).

3.5 Etiquetas y notas

Las etiquetas (tags) se usan para clasificar clientes: VIP, Acepta upgrades, Clienta frecuente, etc. Se asignan desde el perfil.

La nota clave es un campo de texto libre para anotar preferencias, alergias, observaciones importantes. Aparece visible al abrir el perfil.

3.6 Importar / Exportar CSV

Para importar clientes desde un archivo externo o exportar la base de datos:

  1. En Clientes, tocá Exportar CSV (descarga todos los clientes con teléfono y email).
  2. Para importar, tocá Importar CSV y seleccioná el archivo. El sistema detecta duplicados por teléfono.
Función exclusiva de administración Importar y exportar datos de clientes (incluyendo teléfono y email) solo está disponible para el rol admin.

3.7 Detectar y fusionar duplicados

Si hay clientes repetidos en la base de datos, el sistema puede detectarlos automáticamente.

  1. Tocá Detectar duplicados (visible solo para admins).
  2. El sistema muestra pares de clientes que comparten teléfono, email y nombre/apellido similares.
  3. Para cada par, elegís cuál mantener. El que se elimina transfiere todo su historial (turnos, pagos, etiquetas, notas) al que queda.
Esta acción es irreversible. Revisá bien antes de confirmar. El historial se une correctamente, pero el registro eliminado no se puede recuperar.

4.Agenda 🕐

La agenda visual muestra todos los turnos del día organizados por columna de colaboradora. Podés navegar a cualquier fecha con las flechas o el selector de fecha.

4.1 Crear turno

  1. Tocá un espacio vacío en la agenda (en la columna de la colaboradora y el horario deseado).
  2. Se abre el formulario de turno. Completá: cliente, servicio, hora de inicio y duración.
  3. Opcionalmente: agregá una nota interna o servicios adicionales al turno.
  4. Tocá Guardar turno.

Si el cliente no existe, tocá + Crear cliente desde el mismo formulario.

4.2 Editar y cancelar turno

  1. Tocá el turno en la agenda.
  2. En la ficha, tocá Editar para modificar datos, o Cancelar turno para cancelarlo.
Cobrar desde la agenda Desde la ficha del turno podés tocar Cobrar turno para ir directo a caja con el cliente y servicio precargados. Es la forma más rápida y evita errores.

4.3 No show

Si el cliente no se presentó, marcá el turno como No show desde la ficha del turno. El turno queda registrado como no concretado sin eliminarlo del historial.

4.4 Bloqueos

Para bloquear un horario (almuerzo, capacitación, limpieza, etc.) sin crear un turno, usá la opción Bloquear horario en la ficha que se abre al tocar un espacio vacío.

5.Caja ◇

La caja registra todos los movimientos de dinero del salón: cobros, señas, gastos, retiros y el arqueo diario.

5.1 Abrir caja

  1. Tocá Abrir caja.
  2. Ingresá el monto de apertura (el efectivo con el que empieza la caja del día).
  3. Seleccioná quién abre y confirmá.
La caja debe estar abierta para registrar cobros en efectivo. Transferencias y otros métodos se pueden registrar aunque la caja esté cerrada.

5.2 Cobrar un servicio

La forma más rápida es desde la Agenda (tocás el turno → Cobrar turno). Desde Caja también podés hacerlo manualmente:

  1. En la pestaña Registrar, seleccioná el cliente (buscalo o crealo).
  2. Tocá + Agregar servicio.
  3. Seleccioná la colaboradora y el servicio. El precio se carga automáticamente.
  4. Agregá adicionales, propina o descuento si corresponde.
  5. Tocá Continuar a cobro →.
  6. Seleccioná el método de pago e ingresá el monto.
  7. Tocá Confirmar venta.
Pago combinado Si el cliente paga con dos métodos (ej: $5.000 efectivo + resto por transferencia), activá "Método adicional" en la pantalla de cobro para dividir el pago.

5.3 Descuentos

En cada línea de servicio, tocá % descuento para aplicar uno de los tres tipos disponibles:

TipoCuándoComisiónCobro
Canje Servicio gratuito (gift, canje) Sobre precio catálogo completo $0 al cliente
Desc. empleada Colaboradora se atiende Sobre precio con descuento Se descuenta del sueldo (no paga en caja)
Bonificación cliente Descuento especial a cliente Sobre precio final cobrado Precio menos el % al cliente
El descuento aplica sobre el total de la línea Incluye el precio del servicio más todos los adicionales seleccionados.

5.4 Señas y anticipos

Registrar una seña:

  1. Tocá Registrar seña en Caja.
  2. Seleccioná el cliente, el turno asociado y el monto.
  3. Confirmá el método de pago.

Al cobrar el turno más adelante, el sistema detecta la seña disponible y la descuenta automáticamente del saldo a cobrar.

5.5 Gastos y retiros

AcciónCuándo usarla
Registrar gasto (caja) Compra chica pagada con efectivo de la caja (café, insumos menores). Botón Gasto.
Registrar retiro Retiro del día para depósito bancario, pago de propinas, u otro. Botón Retiro.
Gastos en Finanzas Gastos mayores (alquiler, sueldos, insumos del mes). Se registran en el módulo Finanzas → Gastos.
Todos estos movimientos aparecen en el Ledger de efectivo Los gastos de Finanzas pagados en efectivo también aparecen en el ledger del día correspondiente.

5.6 Ledger — Ver todos los movimientos

El Ledger es el registro cronológico de todos los movimientos de dinero. Se accede desde la pestaña Ledger en Caja.

Sub-pestañaQué muestra
EfectivoTodos los movimientos en efectivo: apertura, cobros, retiros, gastos. Con saldo corriente hora por hora.
TicketsResumen de cada ticket del día: cliente, servicios, medio de pago, total.
Por métodoTotales agrupados por método de pago (efectivo, transferencia, débito, etc.).

Podés cambiar la fecha con el selector para ver días anteriores.

5.7 Anular ticket o seña

Anular un ticket: en la pestaña Tickets, los tickets del día tienen el botón Anular ticket. Se pide un motivo. El ticket anulado queda con fondo rojo y el motivo visible.

Anular una seña: en el ledger o en el perfil del cliente, buscá el pago de seña y anulalo. Requiere rol admin.

5.8 Cerrar caja

  1. Tocá Cerrar caja.
  2. El sistema muestra el efectivo esperado según los movimientos registrados.
  3. Contá el dinero físico e ingresá el monto contado.
  4. El sistema calcula la diferencia (sobrante o faltante) y la registra.
  5. Opcionalmente agregá una nota de cierre.
  6. Confirmá el cierre.
El cierre guarda el historial completo Al cerrar la sesión, todos los retiros y gastos del día quedan guardados en el historial de cierres, accesible en el Ledger para fechas anteriores.

6.Catálogo de servicios

El catálogo define los servicios disponibles, sus precios y grupos. Desde aquí se configura lo que aparece en Caja al cobrar.

6.1 Agregar o editar un servicio

  1. Andá a Catálogo en el menú.
  2. Para agregar: tocá + Nuevo servicio. Para editar: tocá el servicio existente.
  3. Completá nombre, grupo (Manicuria, Eyebrow & Lash, etc.), precio y duración estimada.
  4. Guardá.
Cambios de precio afectan ventas nuevas Los tickets ya registrados conservan el precio al momento del cobro. Cambiar el precio en catálogo solo afecta ventas futuras.

6.2 Adicionales

Los adicionales son servicios extras que se suman a la línea principal en caja (ej: Ojo de gato, Retiro de semi). Se configuran en el catálogo y aparecen como chips seleccionables al registrar una venta.

También podés configurar el umbral de "Alto gasto" en Catálogo: un monto y período que, si lo supera una cliente, le agrega automáticamente la etiqueta "Alto gasto" en su perfil.

7.Equipo

Gestión de colaboradoras del salón: datos, roles, comisiones y usuarios de acceso.

7.1 Crear colaboradora

  1. Andá a Equipo y tocá + Nueva colaboradora.
  2. Ingresá nombre, apellido, especialidad y datos de contacto.
  3. Guardá. Luego podés vincularla a un usuario de acceso desde la sección Usuarios.

7.2 Configurar comisiones

En el perfil de cada colaboradora podés definir el porcentaje de comisión por grupo de servicio (ej: Manicuria 30%, Eyebrow 25%). Esto se usa en el cálculo de liquidaciones.

8.RRHH

Liquidaciones de sueldo y deducciones de colaboradoras.

8.1 Deducciones

Las deducciones reducen el sueldo de la colaboradora. Pueden ser manuales o automáticas:

TipoOrigen
ManualSe carga a mano desde RRHH (adelantos, préstamos, etc.).
Servicio empleadaSe genera automáticamente cuando se registra una venta con descuento tipo "Empleada" en caja.

8.2 Liquidaciones

  1. En RRHH, seleccioná la colaboradora y el período.
  2. El sistema calcula la comisión sobre todos los servicios realizados en el período, usando el porcentaje configurado en Equipo.
  3. Se descuentan las deducciones del período.
  4. Revisá el detalle y confirmá la liquidación.
Comisión en servicios con Canje Para los canjes, la comisión se calcula sobre el precio de catálogo (no sobre $0), dado que la colaboradora realizó el servicio completo.

9.Finanzas

9.1 Registrar gastos

  1. Andá a Finanzas → Gastos.
  2. Tocá + Nuevo gasto.
  3. Completá: fecha, categoría (Insumos, Alquiler, Servicios, etc.), descripción, monto y método de pago.
  4. Guardá.
Los gastos en efectivo aparecen en el Ledger Si registrás un gasto con método "Efectivo" en Finanzas, va a aparecer en el Ledger de efectivo de ese día.

9.2 Contador mensual

El contador de Finanzas agrupa los gastos por categoría y mes, y los compara contra el presupuesto mensual configurado. Podés filtrar por período y exportar el detalle.

10.Comunicaciones

GLAMB OS envía emails automáticos a los clientes en los momentos clave del turno.

10.1 Emails de turno

EmailCuándo se envíaQué incluye
Confirmación de turno Al crear el turno en agenda. Fecha, hora, servicio y botón para agregar al calendario.
Recordatorio automático 4 horas antes del turno (Cloud Function automática). Fecha, hora y servicio. Sin nombre de colaboradora.
Para que funcionen los emails, el cliente debe tener email cargado. Sin email no se envía nada. Siempre pedí el email al crear o actualizar un cliente.

10.2 Historial de recordatorios enviados

En Comunicaciones podés ver el log de todos los recordatorios enviados, con estado de entrega (enviado / error).

11.Athenas — Asistente IA

Athenas es la inteligencia artificial integrada en GLAMB OS. Podés hacerle preguntas en lenguaje natural sobre el negocio.

Ejemplos de consultas

  • "¿Cuántas visitas tuvo María García este mes?"
  • "¿Qué servicio es el más vendido en Manicuria?"
  • "¿Cuáles son los clientes que no vienen hace más de 60 días?"
  • "¿Cuánto facturó el salón esta semana?"
  • "¿Qué turno tiene Giuli mañana a las 15?"
Athenas necesita una API key de Claude (Anthropic) Si Athenas no responde o dice que falta configuración, avisale a administración para que configure la API key en Ajustes → Athenas.

12.Preguntas frecuentes

La app no muestra los últimos cambios

Cerrá completamente el navegador y volvé a abrirlo. Si sigue igual, borrá la caché del navegador o probá desde modo incógnito.

¿Cómo sé si la caja está abierta?

En Caja, el indicador de estado muestra "Caja abierta" o "Caja cerrada" con la hora de apertura. Si está cerrada, no podés registrar cobros en efectivo.

¿Qué pasa si me equivoqué al cobrar?

Anulá el ticket (botón en la pestaña Tickets) e ingresá el cobro nuevamente. Los tickets anulados quedan registrados con fondo rojo y el motivo visible.

Una cliente tiene saldo de seña pero no aparece

El saldo de seña se aplica automáticamente al cobrar. Si no aparece, verificá que la seña esté asociada al turno correcto o al cliente en la pantalla de cobro.

¿Cómo veo los movimientos de días anteriores?

En Caja → Ledger, usá el selector de fecha. Para fechas anteriores se muestran los cobros y los movimientos de la sesión de ese día si fue cerrada correctamente.

¿Puedo crear usuarios para el equipo?

Sí, desde Equipo → Usuarios (solo admin). Completás email, contraseña temporal y asignás el rol. La colaboradora recibe acceso con esas credenciales.
